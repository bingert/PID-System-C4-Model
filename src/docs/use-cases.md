# User Stories

Die User Stories werden nach dem Schema
* Als **Rolle** möchte ich **Ziel/Wunsch**, damit **Nutzen/Mehrwert**.
definiert.

## 1 Auflösung von PIDs

Als **Mitarbeiter der Verwaltung** möchte ich **PIDs auflösen**, damit **ich auf die referenzierten Information zugreifen kann**



## 2 PID Selfservice

Als **Mitarbeiter der Verwaltung** möchte ich **einzelne PIDs erzeugen**, damit **ich diese in Dokumente/Formulare eintragen kann**

## 3 Automatisierte PID Erzeugung

Als **System Administrator** möchte ich **große Mengen an PIDs automatisiert erzeugen**, damit **eigene Datensätze/Dokumente mit PIDs versehen werden**


## Rollen

* Mitarbeiter der Verwaltung
* System Administrator
