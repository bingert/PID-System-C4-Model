# User Stories

definiert.

## 1 Auflösung von PIDs

Als **Mitarbeiter der Verwaltung** möchte ich **PIDs auflösen**, damit **ich auf die referenzierten Information zugreifen kann**

Erläuterung: Die in Formularen, Webseiten oder anderen Dokumenten dargestellten PIDs verweisen auf relevante Informationen. Mitarbeitende der Verwalung sollen die Möglichkeit haben einzelne PIDs in, z.B., einem Webformular einzugeben.

## 2 PID Selfservice

Als **Mitarbeiter der Verwaltung** möchte ich **einzelne PIDs erzeugen**, damit **ich diese in Dokumente/Formulare eintragen kann**

Erläuterung: In verschiedenen Anwendungsfällen sollen die Mitarbeitenden die Möglchkeit haben einzelene PIDs für eine Ressource in, z.B., einem Webformular zu erstellen. Dazu muss die URL-Referenz eingetragen werden.


## 3 Automatisierte PID Erzeugung

Als **System Administrator** möchte ich **große Mengen an PIDs automatisiert erzeugen**, damit **eigene Datensätze/Dokumente mit PIDs versehen werden**

Erläuterung: In der Dienstentwicklung und -betrieb sollen Resourcen (Objekte) automatisiert mit PIDs versehen werden. Dafür muss eine Web-Schnittstelle (API) bereit gestellt werden.

## Rollen

* Mitarbeiter der Verwaltung
* System Administrator
